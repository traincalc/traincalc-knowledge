# TrainCalc Knowledge Base

Operational memory and strategic context for TrainCalc. Markdown and Git are the canonical format and history; Obsidian is an optional reading and editing interface.

Start with:

1. [NOW.md](NOW.md)
2. [STRATEGY.md](STRATEGY.md)
3. [CURRENT-STATS.md](CURRENT-STATS.md)
4. [DECISIONS.md](DECISIONS.md)
5. The relevant task or weekly review

Use this repository to record current state, metrics, decisions, confirmed lessons, tasks, page priorities, ideas, and weekly reviews. Prefer a small update to the relevant existing file over creating new structure.

Do not store credentials, API keys, client secrets, personal user data, raw chat transcripts without extracted conclusions, or outdated metrics presented as current.
